# Public product-claim boundaries

This public counterpart preserves claim-boundary regression coverage without
publishing internal marketing plans. The public README describes the source
snapshot; feature availability is controlled separately by deployment settings.

- Opsis is an independent, read-only asset intelligence workspace.
- Public-provider evidence and private owner-entered records are different things.
- Missing provider data is not zero holdings, zero activity, or proof of safety.
- A current-block snapshot is not a finality guarantee.
- Local encrypted records require the same browser profile and origin or a
  verified encrypted backup restore. Browser storage is not guaranteed forever.
- Replay Actions does not infer or reuse historical intent. It uses fresh user
  inputs, fresh evidence, and an official external execution or checkout venue.
- Token-paid query packs, token economics, and future cloud features must not be
  presented as enabled rights or current functionality without separate evidence.
- No provider name, trademark, registry match, or code publication implies
  endorsement, authenticity, solvency, custody, redemption eligibility, or returns.
